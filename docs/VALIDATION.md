## v0.1.0 历史记录

## 已完成

- 官方 skill-creator `quick_validate.py`：通过。首次遇到宿主默认 GBK 编码失败，使用 Python `-X utf8` 重跑通过，未改动官方检查器。

- 独立行为验证：初版14例发现表述风险并修订；新版16例重新执行，受测 Agent 未读取评分标准或实际用户历史。主 Agent 对照公开 rubric 审核，16项满足该样本集的边界要求。完整实际回答见 [测试输出](../evals/observed-2026-09-23.md)。

## 证据边界

单元测试验证配置修改行为；格式检查验证技能结构；行为案例验证部分目标判断。三者均不证明真实任务的结果质量，也不证明技能会在所有会话自动加载。

独立测试使用同一产品环境下的独立 Agent 上下文，不是外部人工认证，也不是多模型统计试验。

尚未验证其他操作系统的实际文件权限/符号链接行为，未验证所有宿主的技能发现机制，未开展长期 A/B 对照或量化返工成本。无零错误、必然生效或节省费用的承诺。

## 安装链路

- GitHub 仓库已创建并确认 `PUBLIC`，默认分支为 `main`，远端文件清单仅包含本项目。
- 使用官方 `skill-installer` 的 GitHub download 路径从公开仓库安装成功，没有用本地复制冒充远程安装；四个技能文件逐一 SHA-256 比对一致，安装后的技能格式检查通过。
- 经用户授权，将通用规则追加到全局指令并保存备份。应用后回读确认区块存在，再次预览返回 `unchanged`；原全局文件前缀逐字节保持不变。未上传全局文件或备份。
- 首次沙箱内 Git 推送遇到 Windows TLS 错误；获准在沙箱外、仅本次信任该新建仓库后推送成功。没有修改全局 Git 信任、凭据或证书校验设置。
- 文件层面的安装与配置已验证；当前会话尚未重新加载新全局指令，不能声称已验证所有后续会话的自动触发。建议新会话检查技能可见性及全局规则加载。
